# 🍴 Receitas à Mesa

Aplicação web de receitas culinárias, feita à mão com **HTML, CSS e JavaScript puros**, sem frameworks nem código de servidor — tudo guardado no navegador.

🔗 **Site publicado:** https://marcelomorenodeoliveira-hash.github.io/ReceitasAMesa/

---

## ✨ Funcionalidades

- Página inicial com categorias, receita do dia e destaques
- Pesquisa de receitas por nome e categoria
- Página de detalhe com ingredientes e passo a passo
- Guardar receitas nos **favoritos** (LocalStorage)
- Formulário para **adicionar novas receitas**
- Campo de pesquisa interativo
- Layout totalmente responsivo (telemóvel, tablet, computador)

## 🧰 Tecnologias

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura e semântica |
| CSS3 | Design, animações e responsividade |
| JavaScript (ES6+) | Lógica da app, pesquisa, favoritos, LocalStorage |

## 📁 Estrutura

```
ReceitasAMesa/
├── Index.html      → página inicial
├── receitas.html   → listagem e pesquisa
├── receita.html    → detalhe de uma receita (ex.: ?id=1)
├── favoritos.html  → receitas guardadas
├── adicionar.html  → formulário para adicionar receita
├── style.css       → estilos e design
└── script.js       → lógica da aplicação
```

## 🚀 Como usar

1. Descarrega ou clona este repositório;
2. Abre o ficheiro `Index.html` em qualquer navegador;
3. Explora por categorias, pesquisa por nome, guarda favoritos e adiciona receitas.

> Podes hospedar gratuitamente no [GitHub Pages](https://pages.github.com/) — é onde este site está publicado.
